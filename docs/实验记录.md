# 实验记录

所有数字来自本机实际运行（Windows 11 · Python 3.12.10 · numpy 2.5.3 · 2026-10-24），
随机种子固定，可复现。运行方式：`python labs/<目录>/lab.py`。

## 01 线性回归：闭式解 vs 梯度下降

- 设定：n=120，y = 3.0 + 1.8x + N(0, 0.8)，seed=42
- 正规方程解 w = [2.9928, 1.7981]；梯度下降（lr=0.05, 3000 轮）收敛到同一值
- **权重 L2 差：1.79e-15**（浮点机器精度），两法 MSE 均为 0.6499
- 损失从 18.17 降至 0.65
- 结论：全批量梯度下降在凸二次目标上确实收敛到闭式解。

## 02 分类：逻辑回归 vs 决策树（双月牙）

- 设定：n=300，noise=0.15，seed=0（`make_moons` 的 numpy 复刻）
- 逻辑回归（lr=1.0, 3000 轮）：**86.7%** —— 线性边界无法贴合月牙
- 决策树（max_depth=4）：**91.3%** —— 轴平行的阶梯边界
- 结论：模型容量与边界形状匹配问题本身，比"哪个算法更强"更根本。

## 03 MLP：XOR 与环形两分类

- XOR（2-8-2 tanh，lr=1.0, 3000 轮，seed=42）：4/4 全部预测正确，loss 收敛到 **2.23e-4**
- 环形两分类（2-16-16-2 tanh，lr=0.5, 1500 轮，seed=7）：训练集准确率 **100%**，loss 4.48e-4
- 结论：一个隐藏层足以表达 XOR；两层隐藏层可拟合环形分界。

## 04 注意力：因果掩码语义

- 受控夹具：7 个 token，手工设定名词与代词的表征方向（**不声称**模拟真实语言模型）
- 上三角注意力权重**严格为 0**；每行权重和 = 1
- 代词「它」的注意力最高键是「小猫」（0.28），两个名词合计权重 0.470
- 结论：掩码语义与"注意力集中在语义相关词"的行为均按设计成立。

## 贪心 CART 与 XOR

值得单独记录的发现：**贪心决策树不能用深度 2 干净拟合 XOR**。

- 对四角聚类 XOR 数据（每角 40 点），根节点任何 0.5 处划分的基尼增益恰为 0
  （左右都是 50/50 混合），而把 (0.2, 0.2) 角切出一小片纯类的划分反而有微小增益
- 实测（seed=1）：root 贪心划分选在 x₀=0.194（增益 0.0108），深度 2 准确率仅 75%，
  深度 3 → 95.6%，**深度 4 → 99.4%**，深度 5 → 100%
- 均匀分布 XOR 上更糟：深度 2 只有 64%
- 教学含义：贪心 ≠ 全局最优；ID3/CART 的"逐层剥纯"行为在异或类问题上需要额外深度。
  scikit-learn 的树同样如此（可自行验证）。
